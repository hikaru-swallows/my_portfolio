# 自己紹介サイト

HTML・CSS・JavaScriptを使用して制作したポートフォリオサイトです。

## サイト概要

自身のプロフィールやスキル、制作実績を掲載した自己紹介サイトです。

閲覧者に分かりやすく情報を伝えられるよう、シンプルで見やすいデザインを意識して制作しました。

また、デザインや世界観による印象の違いを表現するため、スタンダード版・ポケモン風版・FIRE EMBLEM風版の3種類のプロフィールページを制作しています。

## 掲載内容

- 自己紹介
- スキル紹介
- 制作実績
- お問い合わせ情報

## 制作作品

- スタンダードプロフィール
- ポケモン風プロフィール
- FIRE EMBLEM風プロフィール

## 使用技術

- HTML
- CSS
- JavaScript

## 工夫した点

- 閲覧者が読みやすいレイアウトを意識した
- デザインごとに異なる世界観を表現した
- ナビゲーションを設置し、必要な情報へ移動しやすくした
- 配色や余白を調整し、視認性を向上させた

## 制作目的

HTML・CSS・JavaScriptの学習成果をアウトプットすることを目的として制作しました。

また、自身のプロフィールや制作実績を分かりやすく発信するポートフォリオサイトとして活用しています。
